🏋️‍♂️ WT Gym SQL Data Analysis Project

    About the Project
This project analyzes data from a gym to uncover insights related to membership, payments, check-ins, and customer trends. It was done using SQL to answer real business questions.

    🎯 Project Goals
- Understand gym revenue trends
- Track member activity and retention
- Analyze gym usage by day and time
- Explore age and gender demographics of members

   🗂️ Tables Used
- `members`
- `checkins`
- `membership_types`
- `payments`

    ✅ Features
   1. Membership & Revenue Analysis
- Total revenue per month
- Most popular membership type
- Average revenue per member

  2. Customer Retention
- New members each month
- Members inactive for 30/60 days
- Retention by membership type

  3. Gym Usage Trends
- Busiest days of the week
- Seasonal check-in patterns
- Top 10 most active members

  4. Demographic Insights
- Member breakdown by gender and age
- Average age by membership type

   🔄 Process (Simple)
1. Explored all gym tables
2. Wrote SQL queries to answer key questions
3. Used joins, filters, and aggregates to find insights
4. Organized and cleaned the results

   📂 Files Included
- `gym_analysis.sql` – All SQL queries
- `README.md` – This project overview
